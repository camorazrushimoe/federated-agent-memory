# M2 blind-answering BIND layer

240 items (80 convos x 3 candidates) in two seeded, shuffled, anonymized pass inputs; mapping + manifest for the join. Stage a per-pass directory with `stage_blind_pass.py stage --bind <this dir> --pass <1|2> --stage-dir <dir>` and hand THAT directory (only) to a fresh agent session.

- `PROTOCOL-m2-blind.md`
- `candidate_mapping.json`
- `pass1_check.py`
- `pass1_input.jsonl`
- `pass1_prompt.md`
- `pass2_check.py`
- `pass2_input.jsonl`
- `pass2_prompt.md`
- `passes_manifest.json`
