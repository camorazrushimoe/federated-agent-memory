# H2v2 — закрытый словарь процедур

Заморожен до первого S2. Менять только новым run id и правкой этого файла
плюс `bin/config.py` плюс `PROMPTS.md` §2.

Это не тикетная таксономия колл-центра. На ABCD-срезе золото режет
**процедуру** (суброут), не «тип обращения». См. [`FINDINGS.md`](./FINDINGS.md).

`unlock` / `unlock_guideline` на вход тегеру MUST NOT подаваться.
Словарь написан по транскриптам и золоту; тегер видит только чат.

## constraint (аудит, не S3)

`none` · `missing_data` · `policy_block` · `system_limit` · `identity_required` · `one_off_exception`

В поиск и в `tag_key` не входит.

## ending (аудит, не S3 и не полка рейтинга)

`resolved_info` · `resolved_action` · `resolved_exception` · `unresolved` · `escalated` · `unknown`

На срезе золото ending не использует. После S2 пишем распределение.
Если одна корзина >80% — ось мёртвая, **не** чинится порогом и **не** возвращается в S3.
