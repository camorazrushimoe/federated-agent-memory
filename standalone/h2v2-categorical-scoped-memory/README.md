## Гипотеза

После закрытия чата кладём **всю сессию** в пул с id процедуры из фиксированного
списка (~31). Новый диалог ищет сессии **той же процедуры**. Рейтинг живёт на
полке = этот id. Агенту подмешивают целые прошлые чаты.

На ABCD-срезе золото *уже* совпадает с суброутом (393/393). Вопрос эксперимента:
восстановит ли S2 эту ось по транскрипту, без `unlock`.
