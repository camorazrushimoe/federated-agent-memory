# Раунд 0 — что делаем и чего не делаем

Цель раунда: получить одну строку вердикта FFP на замороженном
срезе 60, без ранкера, с живым или replay-S2 из v2.

## Входит

1. Bootstrap из v2 + тот же D0 gold / slice.
2. Теги: replay v2 или один прогон `deepseek-v4-flash` temp 0.
3. D4 как precondition.
4. Пакеты B0 / B_tag / B_raw / B_gold, по одной сессии.
5. Судья на парах tag_vs_b0, tag_vs_raw, tag_vs_gold + 10 swap-audit.
6. `eval_ffp.py` и REPORT.

## Не входит

- S4 rank, S7 update, корпус 1000+200 как измерительный пул.
- Переразметка gold_useful.
- Новый словарь процедур.
- Живой агент, который *отвечает* клиенту.
- Сравнение с H1-карточками.
- Подбор промпта судьи между попытками. `PROMPTS.md` заморожен на
  старте раунда 0.

## Модели

| слот | кто | правило |
|---|---|---|
| tag | `deepseek-v4-flash` | как v2 раунд 0; флаг, не правка |
| gold (уже заморожен) | `deepseek-v4-pro` | не перезапускать |
| judge | флаг `--judge-model` | не flash; лучше другой вендор |

## Стоп-условия внутри раунда

- D4 красный → раунд не доходит до S8.
- parse < 0.95 на первых 20 парах → остановить S8, чинить разбор,
  не копить 180 сырых ответов.
- 401/429 → аборт, без смены провайдера внутри того же run id.

## После раунда

Одна из трёх строк EVAL-PLAN §6.3. Следующий рычаг только из отчёта:

- NOT FIT по net_vs_B0 → гипотеза «целая сессия той же процедуры
  помогает» на этом домене закрыта. Не открывать 1000.
- LIMITS по net_vs_raw → теги не отделились от сырой памяти.
- LIMITS по цене → нарезка сессии, не ранкер.
- FIT → можно обсуждать продукт без ранкера: S3 + свежий/случайный слот.
